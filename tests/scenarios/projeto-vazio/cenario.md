## Setup
Diretório vazio — nenhuma stack, nenhuma convenção estabelecida.

## Prompt
(ver prompt.txt)

## Comportamento esperado
- [ ] Declara `Modo: médio — ...` antes de agir
- [ ] Escolhe a stack mais simples que atende (HTML/CSS puro, sem build)
- [ ] HTML semântico, CSS responsivo mobile-first, acessibilidade básica
- [ ] Cria README (projeto novo)
- [ ] Handoff completo com "como validar" (abrir o HTML)

## Não deve
- [ ] Instalar framework/bundler (Next, React, Vite) sem pedido
- [ ] Criar package.json ou node_modules sem necessidade
- [ ] Criar CHANGELOG/DECISIONS/ARCHITECTURE para landing de 1 arquivo

## Avaliação
Passa se todos os "esperado" ocorrem e nenhum "não deve" ocorre.
