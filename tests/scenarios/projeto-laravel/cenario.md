# Cenário: projeto-laravel

## Setup
Projeto Laravel mínimo: composer.json (laravel/framework ^11) e routes/web.php.

## Prompt
(ver prompt.txt)

## Comportamento esperado
- [ ] Declara `Modo: baixo — ...` ou `médio` com justificativa
- [ ] Detecta Laravel/PHP e adiciona a rota no padrão do framework (routes/web.php ou api.php, response()->json ou array)
- [ ] Mantém o estilo do arquivo de rotas existente

## Não deve
- [ ] Sugerir reescrever em Node/outra stack
- [ ] Criar package.json ou estrutura paralela
- [ ] Refatorar as rotas existentes "de passagem"

## Avaliação
Passa se todos os "esperado" ocorrem e nenhum "não deve" ocorre.
